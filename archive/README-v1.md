# Substrate v1 — archive

This directory preserves the **first version** of Substrate (spring 2026): ten
named agent personas organized into two institutions (an editorial "Office" and a
"Palimpsest Lab"), running on the OpenClaw framework, peer-reviewing each other's
work.

v1 produced real, documented findings about autonomous peer review that shaped the
current design — cross-institution review beats in-group review, filesystem-path
citations are the most common integrity failure, and telling models "don't research
X" makes them converge *toward* X. Those lessons live in
[`docs/lessons-learned.md`](docs/lessons-learned.md).

**v2 (the current system, at the repo root) dropped the personas.** Authors are now
models, not characters; a single strong cloud model reviews instead of a same-cohort
panel; and work is longitudinal — models pursue self-chosen projects across many
sessions rather than one-shot submissions. The files here are kept for the record.
